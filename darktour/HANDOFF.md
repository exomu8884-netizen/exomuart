## 0. 이 프로젝트

**exomu.art/darktour** — 역사 속 소수자의 자리만 골라 걷는 관광 코스 앱.
GitHub Pages 위의 **완전 정적 웹앱**이다. 서버도 빌드 도구도 없다.

```
지역(시도 → 시군구) → 관점(렌즈, 최대 3개) → 기간 → 코스 2안(시간의 길 / 발의 길)
```

관광지가 아니라 **«여기서 누가 지워졌는가»**를 색인한다.
이야기는 우리가 쓰고, 한국민족문화대백과사전이 뒷받침하고, 한국관광공사 TourAPI 는 주소·사진만 붙인다.

```bash
cd darktour
python3 build/validate.py     # 구조 무결성 — 오류 0 이어야 한다
python3 build/audit.py        # 내용 감사 — 확인 대상 목록
```

읽는 순서: **이 문서 → `SPEC.md` → `data/cache/` 아무 파일 하나.**

## 3. 반드시 지키는 규칙

### ① 출처 없는 글은 싣지 않는다

`sources` 는 필수 필드다. **확인 가능한 자료 단위까지만** 적고,
확인하지 않은 쪽수·문서번호·판례번호는 적지 않는다.
근거의 성격은 `evidence` 로 밝힌다 — `record` / `site` / `oral` / `legend`.

`legend` 는 사실이 아닐 수 있다. 그래도 싣는 이유를 화면에 그대로 적는다 —
「사실이 아닐 수 있으나, 이 지역이 무엇을 기억하려 했는지는 사실입니다.」

### ② 중복 등재되는 장소는 손으로 다시 쓰지 않는다

같은 장소가 여러 렌즈 캐시에 들어갈 수 있다 (예: 경복궁 = 성소수자 + 여성).
앱은 `id` 로 합치면서 **먼저 읽은 쪽을 남기므로**, 두 벌의 내용이 다르면
사용자가 고른 렌즈 순서에 따라 다른 글이 보인다.

**반드시 스크립트로 복사한다.**

```python
src = json.loads(pathlib.Path("data/cache/36__people.json").read_text(encoding="utf-8"))
rec = next(copy.deepcopy(p) for p in src["places"] if p["id"] == "jinju-hyeongpyeong")
```

`validate.py` 가 레코드 전체를 비교해 어긋나면 잡는다.

### ③ 커밋 전에 두 검사기를 돌린다

`validate.py` 는 구조를, `audit.py` 는 글을 본다. 둘 다 실제로 버그를 잡아 왔다.
`audit.py` 의 출력은 «틀렸다»가 아니라 «다시 보라»는 뜻이다.

### ④ 캐시를 추가하면 세 곳을 같이 고친다

1. `data/cache/{areaCode}__{lens}.json` 생성
2. `data/coverage.json` 의 `available` 에 등록
3. 모티프를 달았다면 `data/motifs.json` 의 `places` 역색인에도 추가

셋 중 하나라도 빠지면 검사기가 잡는다.

### ⑤ 사람이 사는 곳에는 ★ 예절을 단다

소록도·감천문화마을·동자동 쪽방촌·함박마을·탑골공원처럼 지금 사람이 살거나
일하는 곳에는 `ethics` 를 `★` 로 시작하고 **하지 말아야 할 것**을 구체적으로 적는다.
어떤 곳에서는 「보지 않는 것」이 예의다.

## 4. 막혀 있는 것

이 세션의 네트워크 정책이 **Trusted** 여서 다음이 차단되어 있다.

```
encykorea.aks.ac.kr      백과사전
gubi.aks.ac.kr           구비문학대계 (설화 8만여 건)
kdp.aks.ac.kr            한국학자료통합플랫폼
grandculture.net         향토문화전자대전 (시군구 121곳)
apis.data.go.kr          TourAPI
tile.openstreetmap.org   지도 타일
```

curl·WebFetch·크롬(`--no-proxy-server` 포함) 모두 같은 관문을 지나므로 **우회는 불가능하고 시도하지 않는다.**
프록시 문서도 «report the blocked host, do not route around it» 이라고 명시한다.

**푸는 방법** — claude.ai/code 에서 클라우드 아이콘 → 환경 설정 → **Network access** 를
`Custom` 으로 바꾸고 위 도메인을 한 줄씩 넣는다.
**「Also include default list of common package managers」를 반드시 체크**한다 (안 하면 npm·GitHub 까지 막힌다).
환경 변수 `TOUR_API_KEY` 도 같은 대화상자에서 설정한다. 바꾼 뒤 **새 세션**을 시작해야 반영된다.

### 정책이 열리면 바로 할 수 있는 것

1. `python3 build/fetch_regions.py` → 시군구 코드 채우기 (지금 전부 `null`)
2. `python3 build/fetch_tour.py` → 48곳 TourAPI 매칭 (지금 전부 «관광공사 미등록»)
3. `python3 build/check_grandculture.py` → 문화대전 슬러그 확인 (지금 3곳만 등록)
4. **열녀문·고려장 모티프 스윕** — 이게 가장 큰 병목이다.
   두 모티프는 17개 시도를 모두 커버하지만, 시군별 구체적인 정려 이름과 지명이
   구비문학대계·향토문화전자대전에만 있다. 기억으로 지어내면 ①번 규칙을 어긴다.

빌드 스크립트 3개는 작성돼 있으나 **라이브 API 로는 한 번도 실행되지 않았다.**
첫 실행에서 파라미터 조정이 필요할 수 있다.

## 6. 실제로 밟은 함정 (같은 걸 다시 밟지 말 것)

| 함정 | 어떻게 드러났나 |
|---|---|
| 중복 등재한 경복궁을 두 파일에 **다르게** 씀 | `validate.py` 가 잡음. 렌즈 선택 순서에 따라 다른 글이 보였다 |
| 같은 해 사건이 5개라 **연대순 정렬이 무너짐** | 광주 1980년 항목들. `eraStart` 만으로는 부족해 파일 순서를 동률 기준으로 추가 |
| 수정하면서 `voices`·`story` 만 고치고 **`summary` 를 빠뜨림** | `audit.py` 의 간격 모순 검사가 잡음 |
| 부산·인천 화교 서술에 **문장을 그대로 복사** | `audit.py` 의 반복 표현 검사가 잡음 |
| 일괄 치환으로 `<h4>` 를 `</h3>` 로 닫는 **태그 불일치** 생성 | 정규식 일괄 편집 뒤에는 반드시 `grep` 으로 확인 |
| 근거 없는 수치(거창 「60세 이상 74명」)를 단정적으로 씀 | WebSearch 대조에서 드러남. 자료가 갈리면 범위로 쓰고 `sourceNote` 를 단다 |

**정규식 일괄 편집과 손으로 다시 쓰기가 사고의 두 원인이다.**
반복 작업은 스크립트로, 스크립트 뒤에는 검사기로.
